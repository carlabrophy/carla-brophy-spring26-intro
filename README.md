# Carla Brophy Portfolio Website

## About

This is my personal portfolio website created for my Intro to Web Development course. It highlights my background, work experience, skills, projects, and contact information. The project helped me practice building a website using HTML, CSS, and JavaScript.

## Features

* About Me section
* Experience and Skills sections
* Links to GitHub and LinkedIn
* Contact form with message submission and removal
* Dynamic skills list generated with JavaScript
* GitHub API integration to display my repositories
* Open API page that displays random cat images and breed information

## Technologies Used

* HTML
* CSS
* JavaScript
* GitHub API
* The Cat API
* Axios

## What I Learned

Through this project, I learned how to:

* Manipulate the DOM with JavaScript
* Handle form submissions and events
* Fetch data from APIs
* Create responsive web pages
* Use Git and GitHub for version control

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
